# AGENTS.md

Free-LLM availability dashboard: probes free-tier LLM models from ~15 providers and publishes a static GitHub Pages site (`docs/`). See `README.md` for the full picture; this file covers what agents get wrong.

## Commands

```bash
python3 -m pip install --user -e ".[dev]"   # pytest + ruff
python3 -m pytest                           # dashboard invariants (no live probing, offline-safe)
ruff check .                                # lint (generate_site.py excluded via pyproject)
python3 -m compileall common.py probe_models.py generate_site.py   # CI compile check
./scripts/provider-check.sh                 # direct provider /models probes; exit 2 only on AUTH_ERROR
```

CI (`ci.yml`) runs: `ruff check .` → `pytest -v` → `compileall`. Run all three before pushing.

## Architecture

- **No proxy, no gateway, no compose stack.** `probe_models.py` calls each provider's API directly with a 1-token ping and classifies the result; `generate_site.py` renders the static site into `docs/`; GitHub Actions runs both (`probe.yml` every 30 min, `update-models.yml` hourly cron + on-push).
- **`common.py`** — shared HTTP opener (`SafeRedirectHandler`). Strips `Authorization` / `x-goog-api-key` on cross-host redirects — keep that behavior if touching HTTP fetching. `_is_free(p, key)` is the price-check helper.
- **`probe_models.py`** — probe engine. Constants: `PROBE_TIMEOUT=15`, `ROUND_ROBIN_BUCKETS=1` (every run probes every model), `WATCH_LIST_FAILS=3`. `PROVIDER_PROBES` maps provider → `{env, url, auth, style}`; unknown style → `build_request` returns `None`. Skips providers with no configured key unless `anonymous_ok=True` (only `llm7`). Writes `docs/probes.jsonl` (append) + `docs/availability.json`.
- **`generate_site.py`** — static site builder. **Upstream bot code: do not lint, format, or hand-edit it** (excluded in `pyproject.toml`); it's regenerated by `update-models.yml`.
- **`.env.example`** — all provider keys optional (providers without keys are skipped locally; GH Actions uses repo secrets). Proxy-era variables must NOT be added back.

## Hard invariants (enforced by `tests/test_dashboard.py` — do not break)

- **No literal API keys anywhere.** Tests scan source files for provider key patterns (`sk-or-v1-`, `gsk_`, `AIza`, `gh[pousr]_`, `hf_`, `nvapi-`, `sk-lf-`; skips `.git/`, `docs/`, `.env.example`, binary/lock files). Never commit a real key.
- **Every `os.environ.get(...)` in `common.py`/`probe_models.py`/`generate_site.py` must have a matching `KEY=` in `.env.example`.**
- **`.env.example` must document the major provider keys** (OPENROUTER, GROQ, GEMINI, HF_TOKEN, NVIDIA_NIM, CLOUDFLARE_API_KEY, CLOUDFLARE_ACCOUNT_ID) and must **not** contain proxy-era vars (`LITELLM_MASTER_KEY`, `DATABASE_URL`, `POSTGRES_PASSWORD`, `SYNC_INTERVAL_HOURS`).

## Gotchas

- **`docs/` is bot-generated** — don't hand-edit; changes get overwritten by the hourly cron. Local probing/generation runs do modify it, which is fine (that's the source of the content).
- **`generate_site.py` needs `docs/models.json`** — `probe_models.py` exits 1 if it's missing. The file is committed and refreshed by `update-models.yml`.
- **`classify()` semantics:** 200 + error field → classified by error text (`model_not_found` → not_found, rate/quota → rate_limited); 200 without recognized shape → `ok` unless JSON parse fails/empty → `bad_response`; other 4xx → `bad_response`. Don't "improve" these without updating tests.
- **Testing quirks:** unit tests `importlib`-load `common.py` and `probe_models.py` directly (monkeypatched env, `tmp_path` for rotation) — they need no live network and must stay offline-safe. `test_probe_help_runs` shells out to `probe_models.py --help`; keep the CLI surface stable. Cloudflare probes require `CLOUDFLARE_ACCOUNT_ID` (tests assert `build_request` returns `None` without it).
- **Workflow convention:** when a PR is created for this repo, merge it (squash) and let the deploy workflow run — do not stop at draft stage.
